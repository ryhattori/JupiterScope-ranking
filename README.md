# JupiterScope ranking

The ranking of the mini-games in JupiterScope (Setsuna's Spike Rush, Minerva's Outline!, Juno's Untangle
and Jupiter's Steady Scope).

Rounds are posted from JupiterScope's **Games** window, after signing in with GitHub there. Each posted
round is an issue on this repository, opened by the player's own GitHub account. It holds the round's seed
and every input with its time, so JupiterScope replays each round with the game's rules before listing
it: a round whose replay does not give its score, or that no human could have played, is not ranked.
Each GitHub account holds one place per game.

A posted round shows your GitHub name and, if you choose them, a nickname and a country. Nothing else is
posted.

Please don't open issues by hand: anything that is not a round posted by JupiterScope is closed.
